# Omni Gateway Deployment Guides

This repository provides self-contained guides for registering and running Anypoint Omni Gateway (formerly Anypoint Flex Gateway) using Docker Engine on Linux and Azure Kubernetes Service (AKS). These guides supplement MuleSoft product documentation by offering additional explanations of procedures, commands, and configuration options.

## Guides

| Guide | Description |
| --- | --- |
| [Docker Engine on Linux](docker-linux/README.md) | Register and run Flex Gateway as a Docker container on Linux. |
| [Azure Kubernetes Service (AKS)](aks/README.md) | Register and run Flex Gateway on an AKS cluster. |

## Versions and Validation

The initial releases preserve and refine guides created for earlier Flex Gateway versions. Each guide identifies the product and platform combinations against which its procedure was validated. Future releases will update and validate the guides for current Omni Gateway versions while retaining earlier revisions in the repository history.

## Scope

These guides outline specific registration and startup procedures. They complement, but do not replace, official MuleSoft product documentation. They do not define or recommend production deployment architectures. Each guide details its prerequisites, scope, and exclusions.
